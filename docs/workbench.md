# 工作台功能

## 页面与导航

工作台使用 hash 路由，主页为 `/home`，工具库为 `/tools`，设置为 `/settings`，插件管理为 `/plugins`。插件工具页统一位于 `/tools/<plugin-path>`；用户对菜单重命名不会改变插件 ID 或路由。

插件可声明 `navigation`。支持导航的插件可在“设置 → 导航菜单”中显示或隐藏、重命名、排序和恢复默认值。禁用插件会立即隐藏其导航入口、工具页和 Widget；重新启用后保留此前的菜单偏好。

## 插件管理与独立设置

“插件”页面显示插件加载、激活、运行、禁用与错误状态，并提供打开、启用、禁用、删除托管 ZIP 和进入设置的入口。每个插件的设置在 `/plugins/<plugin-id>/settings` 独立页面中展示；该页管理插件启用状态及其声明式 `settings.fields`，不会混入其他插件的配置。

插件可声明主页 Widget、状态栏信息和透明浮动 Widget。主页 Widget 支持添加、移除、拖动、缩放、固定与布局持久化；浮动 Widget 可置顶和锁定。插件生命周期由运行时统一管理，页面、主页 Widget 与浮动 Widget 不会重复启动同一后台任务。

## AI 聊天与窗口行为

侧栏底部可打开右侧 AI 聊天抽屉。聊天支持系统提示词、多轮上下文、停止、失败重试和新建会话；聊天记录只保留在当前内存会话中。AI 服务在“设置 → AI 服务”统一配置，插件只能读取连接状态并通过受控 API 调用。

Windows 通知区域与 macOS 菜单栏均显示 Hub 图标。点击图标打开菜单，可显示工作台、隐藏工作台或退出。设置中的关闭行为可选择退出应用或隐藏到托盘；真正退出、Cmd+Q 与托盘“退出”始终结束进程。应用以单实例运行，再次启动会聚焦已有窗口。
