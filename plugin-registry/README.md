# 插件声明仓库

这个目录是未来 `wttch-hub-plugin-registry` 仓库的边界，只保存可审查的插件声明，不保存插件源码、用户数据或密钥。当前主项目从这里读取本地声明；未来拆库后，可将整个目录独立发布并由宿主拉取固定版本的 `plugins.json`。

`plugins.json` 的每条记录只描述插件的身份、兼容 API 版本、源码位置和显示信息。开发期的 `source` 使用相对目录；发布期可扩展为经过校验的 GitHub Release ZIP 地址。宿主不能依据声明直接执行未构建的远程代码。
